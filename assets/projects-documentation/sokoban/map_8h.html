Plan non null
dimension(x, y) = (x>3 et y>5) ou (x>5 et y>3)
reference avec i, j coordonnées = (i, 0) = MUR et (0, j) = MUR => toutes les bordures sont des murs

Renvoie
Pointeur Caché Map ou StrMap*
Paramètres
dimensionDimensions du Plan (matrice d'Objet) dans un couple (x, y).
referenceMatrice represantant chaque objet du niveau avec le type Objet, rien de spécial.
nb_cibleNombre de cible présente dans le niveau, les places sur lequels le joeur doit poser des caisses.

◆ map_preMvt()

Bool map_preMvt ( Map  m,
CoupleInt  ajoute 
)

Permet au personnage d'effectuer un mouvemement à une coodonnées donnée.

Renvoie
Un booléen représentant le succès de l'opération de déplacement : Réussi : vrai sinon faux.
Paramètres
mMap ou aura lieu l'opération.
ajouteCouple représentant le mouvement du personnage (doite, gauche, haut, bas) en fonction du x et y.

La fonction effectue le mouvement si et seulement si :

  • la nouvelle cordonnée donnée ne représente pas un mur.
  • le deplacement est d'une unité en x ou y mais pas les deux.
  • si la nouvelle coordonée représente une caisse, qu'il n'y ai pas de caisse ou de mur apres celui-ci.
